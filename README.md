# Wan’s Agent Optimization · Hermes 独立研究室

为已经部署的 Hermes Agent 持续研究、筛选、评测优化方法。本地工程由 Claude Code 开发，本仓库负责形成有来源、有验收条件、可交接的方案。

**当前交付：第一版研究与实施设计，不是已经部署的优化插件。** 本轮未连接本地电脑，未读取 Hermes 私有会话，未修改本地配置，未运行真实 Hermes A/B。改善幅度需要后续实测。

研究日期：2026-10-12 UTC。上游基线：`NousResearch/hermes-agent@54b07ec7f16ec077b86847095f84adf1924eca92`。用户本地版本未知，不能直接套用最新上游配置。

## 结论

以 Hermes 原生能力为基础，建立“明确目标 → 小量相关上下文 → 执行与证据 → 纠错沉淀 → 回归评测”的闭环。先改善日常体验和可观测性，再按失败样本引入外部记忆、模型网关或技能进化。避免同时安装多个全套框架，让成本和失败来源无法归因。

优先解决：重复提问、长任务遗忘、宣称完成却没有产物、工具反复失败、记忆污染，以及后台学习成本不透明。
