# Task Continuity

## When to Use

多阶段任务即将压缩、换会话，或从中断恢复。短任务无需生成交接。

## Procedure

1. 用可用文件工具在用户授权的工作区记录目标、约束、产物、已验证步骤与下一步。
2. 单独记录外部写入回执、待审批和未知结果；引用已有文件，不复制大日志。
3. 在自然阶段边界使用当前环境支持的压缩或会话切换方式，不主动重置未完成审批。
4. 恢复时先读取交接并核对产物，只补未完成动作；未知写结果先查询。

## Pitfalls

交接不是长期用户记忆。摘要不能证明外部写入未执行。缓存稳定性和工具消息配对必须保留。

## Verification

目标、最新纠正和所有必要约束可恢复；旧步骤不重做；不同项目/身份不读取彼此状态。
