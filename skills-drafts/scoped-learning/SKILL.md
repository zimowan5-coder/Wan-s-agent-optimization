# Scoped Learning

## When to Use

用户纠正了可复发的错误，或完成了值得复用的复杂流程。一次性要求不自动推广。

## Procedure

1. 先修正当前任务，再判断属于临时要求、项目事实、稳定偏好还是流程经验。
2. 在已授权工作区记录候选、来源、适用范围、冲突条目与验证场景。
3. 检查已有原生记忆/技能是否覆盖，避免第二套后台观察和重复写入。
4. 按用户授权与原生审批策略，用实际可用的 memory 或 skill_manage 保存；工具未提供时保留候选并说明。
5. 核实写入结果，后续相关任务检验是否复发；用户撤销时清理候选并防止重学。

## Pitfalls

不存密钥或私聊原文。不把一个项目的规则推广到其他项目。不把自评分当作可靠证据。

## Verification

每条经验有范围和来源；临时要求未长期化；冲突可解释；撤销可验证；写入声明有回执。
